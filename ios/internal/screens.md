# Screen catalog

Main-screen Simulator PNGs live in `screens/`. `expected.txt` is the list of catalog names. It includes `cycle-taken-en.png`, `cycle-not-taken-en.png`, and `trends-off-en.png`, the largest-text More picture `more-sample-xxxl-en.png`, the German pictures `sheet-symptom-pill-de.png` and `more-sample-de.png`, and the two widget pictures. `ScreenCatalogTests` writes the English names by navigating a few sessions (empty, sample, Trends fixture, no-scores, and one largest-text More launch), not one app launch per file. It switches to German to write `sheet-symptom-pill-de.png` and `more-sample-de.png`. `widget-medium-before-en.png` and `widget-medium-after-en.png` stay the committed files. `testUserFlow` does not rewrite them. A pull request does not rewrite the catalog. Commit the PNGs. UX reviews the **image diff in Files changed**. The full suite rewrites the catalog unless `SCREEN_CATALOG=0`. The `ids` job still fails if a committed file is missing. The visit preview picture shows Back.

One-off before/after review pictures are pull request attachments at normal text size. They are not stored in the repository.

Do **not** paste screenshot galleries into PR comments. Do **not** use a per-PR dump (`pr-41-simulator` or any pull-request id in the path).

English catalog pictures: Cycle empty, Cycle with a dose marked taken, Cycle with that dose put back, Cycle with data, Trends empty, Trends with data, Trends Choose Symptoms sheet, Trends dot tap, Trends dose-tick sentence, Trends after a selected series is turned off, Trends no-scores, Month, More, More at the largest text size, visit cycle picker, in-app visit PDF preview with Back, add-medication sheet, period sheet, symptom sheet, and the symptom sheet with a wrapped custom name. The German catalog pictures are the New symptom pill (`sheet-symptom-pill-de.png`) and More (`more-sample-de.png`). The widget pictures are the medium card before and after Take. Names are `{screen}-{state}-{locale}.png` (see `screens/expected.txt`). Do not keep old chip-cloud layout shots.

CI fails only if an expected file is **missing**. Pixel drift does not fail the suite. After a layout change, run `.grok/skills/verify-perimedi/scripts/control-perimedi verify` and commit any updated PNGs.
